# Агент сверки спецификаций с чертежами

Проверяет, что оборудование на Планах и Схемах проекта соответствует Спецификации по наименованиям и количеству.

## Запуск

```bash
pip install pymupdf openpyxl --break-system-packages
python -m agent.run <файл.pdf или папка с PDF> -o reports
```

На каждый PDF создаётся `<имя>_сверка.xlsx`.

## Как работает

1. **Классификация листов** по штампу и коду документа: Планы, Схемы, Спецификация (.СО), ВТ, приложения.
2. **Парсинг спецификации** (find_tables): позиция, наименование, марка, ед., кол-во, секция, раздел. Зачёркнутые значения (изм.) отбрасываются, полностью зачёркнутые строки помечаются исключёнными. Поддерживаются повёрнутые на 90° листы (спецификации ЭОМ): координаты слов приводятся к системе таблицы, зачёркивания распознаются и вертикальные.
   - **Обрывки текста печати** («В ПРОИЗВОДСТВО РАБОТ» поверх таблицы) срезаются по краям ячеек: печать наклонная, поэтому в ячейки попадают не слова, а их куски («<< РОИ ТШП-0,66…», «АБО Acti9 iC60L…»), из-за которых марка не находилась на чертежах.
   - **Марка-ссылка на лист** («ПР-01/24-1-ЭОМ лист 14») — это не марка изделия; обозначение берётся из колонки «Примечание» («ЩМк», «1ВП1(8.1)»), диапазоны «ЩМ08..ЩМ12» раскрываются в отдельные обозначения.
   - **Составные изделия** («в составе:») помечаются, их подпозиции связываются с головным щитом.
3. **Подсчёт на чертежах**, раздельно по Планам и Схемам:
   - **штучные позиции (шт./компл.)** — поштучно: число вхождений нормализованной марки;
   - **метровые позиции (м/км)** — в м/км: сумма длин из подписей вида «Марка - 5 м» (допуск ±2%); км спецификации сравниваются с метрами чертежей с пересчётом. Трубы без марки ищутся по типоразмеру из наименования (ø16х2.2).
   - **светильники по ведомости освещения** — если на планах ЭОМ есть «Ведомость осветительного оборудования», количество берётся из её колонки «Кол.» с учётом множителя этажей. Статус «(по ведомости освещения)».
   - **аппараты защиты по схемам** — артикул спецификации («ВА105-1P-010A-B») разбирается на серию, полюсность, номинал и характеристику и сопоставляется с записью на принципиальной схеме («ВА-105 1Р» / «In=10А» / «Ir=B10А»). Поддержана и компактная запись («ВА-103М» / «D6А»). Статус «(по схемам аппаратов)».
   - **кабели по кабельному журналу (.КЖ)** — для ЭОМ и слаботочки метраж берётся из журнала: сумма длин по ключу «марка + сечение» с учётом кратности «1(3×1,5…)». Точный источник, сверка без допуска, статус «(по кабельному журналу)». В спецификациях ЭОМ марка кабеля стоит в колонке «Тип, марка», а сечение — в наименовании, это учтено.
   - **измерение по геометрии (Revit 1:1)** — если длины не подписаны, метраж труб измеряется по векторным линиям планов: масштаб листа определяется автоматически по размерным цепочкам (число в мм / длина размерной линии), цветные сегменты труб относятся к ближайшей метке диаметра (∅16х2.2, Ø25, парные ∅6,35/∅9,52 — длина делится между парой). Статус «(по измерению)», допуск ±15%.
   - **количество из подписи на чертеже** — если рядом с маркой стоит «(10 шт.)» или «- 3 шт.» (схемы компоновки УЭРМ, однолинейные схемы, узлы), количество берётся из подписи, а не из числа вхождений: типовая схема рисуется один раз на все экземпляры. Статус «(по подписям на чертежах)». Для длин учитывается кратность «Труба ВГП 25х3,2 - 2 м (8 шт.)».
   - **уникальные позиционные обозначения** — если позиция спецификации раскрывается в несколько обозначений («ЩМ08»…«ЩМ12»), количество = число найденных обозначений: один тег = одна единица, сколько бы листов её ни показывали. Статус «(по обозначениям на чертежах)».
   - **листы типовых узлов** (подписи «- N шт.» перечисляют состав одного узла) исключаются из метража, а марки, встреченные только там, получают статус «узел: кол-во на 1 узел» вместо расхождения.
   Для листов типовых этажей («План 3-11 этажа») применяется множитель числа этажей.
   Вхождения марки внутри более длинной марки не засчитываются («УЭРМ-2.4» внутри «УЭРМ-2.4 вариант 2»).
   Марка сопоставляется также по ядру, без вендорного хвоста и исполнения: «ЩРн-12 IP31 EKF PROxima» ↔ «ЩРН-12 У3 IP31» на схеме.
   Марка ищется также без учёта пробелов (переносы строк в ячейках спецификации). Если оборудование подписано на чертежах алиасом («Колл-10.1ж»), марка находится через «Расшифровку коллекторов» на листах; карта алиасов собирается по всему документу, а для алиасов без расшифровки марка выводится из числа ответвлений («Колл-7…» → SF40-7-…, если кандидат единственный).
4. **Сверка**: статус «ок / ок (частично) / расхождение / нет на чертежах / есть на чертежах, метраж не подписан / узел: кол-во на 1 узел». Комплектующие внутри щита, не найденные ни на планах, ни на схемах (корпуса, клеммы, шины, сальники), уходят в «Непроверяемые» со ссылкой на головную позицию — это свойство комплекта, а не пропуск. Аппараты защиты, которые на схемах щитов подписаны, продолжают сверяться.

## Отчёт (листы xlsx)

- **Сводка** — итоги.
- **Сверка** — по каждой марке: кол-во Спец./План/Схема, статус, номера страниц PDF для ручной проверки.
- **Непроверяемые** — позиции, не сверяемые по чертежам (м.п., кг, материалы, позиции без марки).
- Колонка «Кабельный журнал, м» заполняется для кабелей, найденных в .КЖ.
- **Классификация листов** — как агент разметил страницы.

## Проверки

```bash
python -m agent.tests_quantities
```

Покрывают распознавание количественных подписей, раскрытие диапазонов обозначений, марку из «Примечания», нормализацию марки и срез обрывков печати.

## Известные ограничения

- Оборудование без марки на чертежах («шкаф металлический наружный») попадает в «нет на чертежах» — требует ручной проверки.
- Одна и та же единица, показанная и на силовом плане, и на плане освещения, считается дважды, если у неё нет уникального обозначения (для обозначений это уже учтено).
- Часть томов (АСУД) содержит шрифты, которые MuPDF не разбирает («unknown cid font type») — текст таких листов извлекается не полностью; проверяйте их вручную.
- Компактная запись аппаратов («ВА-103М» / «D6А») не содержит полюсности, поэтому сопоставляется по серии, номиналу и характеристике без учёта числа полюсов.
- Разделы ВК/АСУД маркируются на чертежах обозначениями систем, а не артикулами — большинство позиций уходит в ручную проверку.
- Схемы квартир повторяют оборудование по типам квартир — счёт по схемам может отличаться от планов; смотрите обе колонки.
- Множитель типовых этажей берётся из названия листа; если состав этажей различается, возможны ложные расхождения.
- Измеренный метраж — оценка по горизонтальной проекции: вертикальные стояки и межэтажные участки в планах не видны (например, сталь 20х2.8: по плану 909 м из 2195 м по спецификации — остальное стояки). Парные фреонометки не позволяют точно разделить диаметры — корректна сумма пары.
